## Chapter Contract

Every chapter begins with README.md. Other directories are added when needed:

- notes/ for original explanations and study guides;
- mental-models/ for concept maps;
- exercises/ for focused API practice;
- experiments/ for prediction-driven investigations;
- tests/ for automated checks;
- scripts/ for chapter-specific helpers;
- observations/ for deliberately retained evidence.

Generated binaries and runtime data belong under build/ and must not be
committed.
